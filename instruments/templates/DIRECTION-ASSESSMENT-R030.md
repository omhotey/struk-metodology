# Оценка направления — краткий шаблон R030

Статус шаблона: предложение для сверки,20.10.2026.
[Правила и шкала](../UNIVERSAL-DIRECTION-ASSESSMENT-R030.md).

**Цель:** …  
**Оцениваем:** способность … получать … для … в условиях/периоде …  
**Профиль/версия и дата оценки:** …

| Направление / существенная подфункция | Что подтверждено сейчас | Нужно для цели | Вывод, разрыв и ближайшее действие |
|---|---|---|---|
| … | Получается / повторяется / управляется / установленное невыполнение. Указать, что ещё не проверено. | Нужный результат/качество, режим, ограничения и срок | Достаточно / есть разрыв / не установлено / не требуется; действие и ожидаемая польза |

К существенному выводу — источник, дата и границы. Причина неизвестности: не спрашивали / недоступно / противоречие / неактуально / другой охват / иное. НП имеет обоснование.

**Проверка ближайшего действия:** что наблюдаем, кто проверяет и когда либо при каком событии.  
**Зависимость/блокер:** … — только если существенно.

Для повторяемости: что является повторением и какие важные условия проверены.  
Для управления: какое отклонение → действие → как проверено последствие.  
При непроверенном более высоком свойстве: «Результат подтверждён; повторяемость не проверена», без утверждения реального низкого предела.

Если используется вспомогательный чек-лист:
- ID родителя и версия: …; что считается одним условием: …
- Правило выполнения родителя: И / ИЛИ / явно заданный порог …
- Подпункты служат основаниями родителя либо отдельными условиями — выбор и его смысл зафиксированы заранее.
- Причина неизвестности сохраняется.
- При другом дроблении сравнение чисел запрещено без общей пересчитанной основы.

Нет обязательного количества направлений/источников, общей суммы баллов и требования заполнить все поля: оставляются те, которые нужны для честного вывода и действия.
