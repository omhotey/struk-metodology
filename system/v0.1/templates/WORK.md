# Рабочая запись продукта и поручения

Копируйте нужные части в согласованное пространство работы. Можно дополнить существующую запись вместо создания новой. Одна запись подходит небольшой задаче; большие предметные модели, доски и источники остаются по ссылкам. Пустое поле означает «ещё не выяснено», а неприменимое — «не применимо» с причиной.

## Короткая запись

Для небольшой задачи достаточно следующих строк, если они позволяют принять решение и продолжить работу. Остальные разделы используйте по потребности; эта запись не дублирует их.

```text
Для кого / вопрос / порученные действия:
С: существенное известно из [источник/дата]; неизвестно [что]:
Т: нужный результат и достаточность; кто принимает:
Р: выбор, альтернатива и причина; остаточный риск / условие возврата:
У: ближайшее действие, кто, зависимость и срок/событие проверки:
К: что наблюдаем против критерия; фактический вывод или «ещё не проверено»:
Передача / следующий шаг / чьё решение или помощь нужны:
```

Пример при недоступных исходниках: вопрос — автоматизировать ли заявки; С — есть только сообщение, фактического процесса не видели; Т — определить обоснованный следующий шаг; Р — разобрать последний случай до выбора технологии; У — уточнить случай в пределах консультации; К — сверить понимание вывода и ближайшего действия. Внедрение и эффект не заявлены.

### Общая работа нескольких продуктов

При необходимости добавьте к одной общей работе строки по продуктам и сквозному результату. Общие действия/стоимость учитываются один раз; частные требования не исчезают.

| Область | Нужный результат и критерий | Кто вправе решить / принять | Основание текущего вердикта | Зависимость и следующий шаг |
|---|---|---|---|---|
| Продукт P1 — ссылка | | | | |
| Продукт P2/P3 — ссылки по необходимости | | | | |
| Сквозная работа I1 | | Принимающий общего прохода назначается явно | | |

Принятие P1 не закрывает P2/P3 или сквозной результат. Три частных одобрения не доказывают, что общая работа проходит. При конфликте сохраните раздельные вердикты и передайте решение владельцу соответствующих целей/ограничений.
