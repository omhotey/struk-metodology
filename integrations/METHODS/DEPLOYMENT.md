# Подключение STRUK, Product Lead и Контура — R034/R035

21.10.2026. Основание — [прямое поручение Юрия](../../governance/sources/REQUEST-R034.md); границы владельцев — [R033](PROTOCOL.md). Это подключение инструкций, не новая версия методологий. Актуальное уточнение — [R035](../../governance/sources/REQUEST-R035.md): существующая персонализация текущего приложения соответствует пользовательскому AGENTS.md и редактируется целиком с сохранением нужных правил.

## Что включается

| Слой | Когда | Вход |
|---|---|---|
| STRUK | Постоянно, с глубиной по задаче | [Переносимое ядро](../../skills/struk/references/system-instruction.md); установленный struk |
| Product Lead | Продуктовое/бизнесовое решение, диагностика, приоритеты, услуги, практика PL | [Адаптер владельца](../../methodology/PRODUCT-LEAD-ADAPTER.md), затем нужные источники |
| Контур | Явное поручение создать проект по методу или подключить его к названному проекту; затем действующие роли проекта | Установленный contur; [вход владельца](<D:/Project/AiContur/AC Admin/docs/integrations/CONTUR-CLIENT-INSTRUCTION.md>) |

Применение метода не передаёт владение его разработкой, не запускает клиентское исполнение и не создаёт дополнительных разрешений. Не превращать обычную беседу в повторное внедрение проекта. Исходник Контура содержит широкие правила согласования; его дальнейшую редактуру ведёт владелец через AC Разработка. Действуют приоритет инструкций и прямое поручение Юрия.

## Codex на этой машине

В R034 к постоянному ядру STRUK/R029 добавлен один блок [маршрутизации](CODEX-ROUTING.md). R035 сохраняет оба этих блока и пересматривает остальную инструкцию целостно: [USER-INSTRUCTIONS.md](USER-INSTRUCTIONS.md). Активное назначение — D:/AI/Codex/home/AGENTS.md, а не отдельное поле на1500символов. Установленные STRUK/Контур и принятые PL-оригиналы не переписываются. Отдельный PL-скилл не нужен для этой маршрутизации.

Проверять профиль, отсутствие AGENTS.override.md, сохранённый блок и доступность целевых файлов. Проверка skills/list подтверждает обнаружение клиентским сервером; это отдельное свидетельство от чтения файлов, выбора в интерфейсе и применения моделью. Не размножать установку в другой каталог только из-за различия новой документации и существующего профиля.

Официальная документация описывает [глобальный AGENTS.md и приоритеты](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [обнаружение и вызов навыков](https://learn.chatgpt.com/docs/build-skills), [skills/list](https://learn.chatgpt.com/docs/app-server#skills). Уже запущенная сессия может иметь прежние инструкции; фактическое применение обновления проверяется в целевом сеансе.

## Персонализация текущего приложения — уточнение R035

Присланный Юрием текст побайтно совпал с D:/AI/Codex/home/AGENTS.md; %USERPROFILE%/.codex указывает на этот профиль. [Официальная документация персонализации](https://learn.chatgpt.com/docs/reference/settings#personalization) описывает редактирование AGENTS.md выбранной машины. Поэтому прежняя рекомендация вставить короткую инструкцию в это поле была ошибкой назначения и могла удалить нужные правила среды.

Для этого назначения применяется полная [USER-INSTRUCTIONS.md](USER-INSTRUCTIONS.md), со сверкой [R035](../../research/USER-INSTRUCTIONS-REVIEW-R035.md). Короткую CHATGPT-INSTRUCTIONS.txt сюда не подставлять. Исходный текст, прочитанные настройки, целостная редакция и результат записи проверяются отдельно. Ручная замена поля не нужна, когда активный файл уже обновлён и совпадает с проверенной редакцией.

## Другие поверхности ChatGPT и отдельные GPT

Облачный ChatGPT, именованный GPT и другой профиль — отдельные назначения. Их настройки этим изменением локального файла не считаются настроенными. Перед последующей интеграцией сначала получить действующую инструкцию именно целевой поверхности и её ограничения; готовить объединённый текст с сохранением нужных правил. Не переносить пути Windows и локальные инструменты как гарантированный доступ облака.

[CHATGPT-INSTRUCTIONS.txt](CHATGPT-INSTRUCTIONS.txt) остаётся кратким переносимым материалом1348символов; [CHATGPT-PACKAGE.md](CHATGPT-PACKAGE.md) — подробным пакетом. Ни один не является безопасной универсальной заменой непустой настройки. Для полной предметной работы нужны относящиеся разрешённые методические источники по карте PL/Контура, без клиентского корпуса и секретов.

Прежняя браузерная попытка R034 остановлена Computer Use по неопределённому URL; она не подтверждает сохранение в облачном аккаунте. R035 исправляет определение назначения по предоставленному тексту и официальной документации; браузерная защита не обходилась.

## Проверка применения

| Запрос | Ожидаемое применение |
|---|---|
| «Переведи одну фразу» | Прямой перевод; без PL-пакета и Контура |
| «Обоснуй приоритет продукта при данном бюджете» | STRUK + PL; допущения и связь с целью |
| «Рекомендации верны по ссылкам, но результата нет» | Проверить требование, разрыв, действие и свидетельство результата |
| «Сколько осталось?» во время поручения | Краткий статус, исходная задача сохраняется |
| «Подключи Контур к указанному проекту, сначала только чтение» | Явный вход, граница источников, без записи/миграции |
| «Исправь техническую опечатку в готовом проекте» | Разрешённая правка и нужная проверка, без повторного внедрения |
| «Прочитай локальный файл» в облаке без доступа | Честно назвать пробел, продолжить доступную часть |

Это сценарии последующей проверки поведения, не выполненный независимый прогон. Новая инструкция, структурная валидность, обнаружение, применение, приёмка и эффект оцениваются отдельно. Фактические проверки этого прохода — [отчёт](../../research/METHODS-INTEGRATION-R034.md).
