Дата: 21.10.2026, Europe/Moscow. Статус: saved_verified_drafts.
Основание: [прямое поручение R039](../../governance/sources/REQUEST-R039.md).
Машинная квитанция: [IMPORT-RECEIPT-R039.json](IMPORT-RECEIPT-R039.json).

## Результат

На локальном WordPress Lab http://localhost:8080 созданы 16 статей СТРУК, все со статусом draft. Публикаций — 0. Созданы корневая категория СТРУК и пять дочерних разделов, назначены 20 тематических тегов. До загрузки авторизованная проверка не обнаружила ни одного документа или категории.

Для просмотра нужны права пользователя WordPress. Адреса черновиков получены из API; текущий формат ссылки — ?post_type=docs&p=ID. Публичные красивые URL в этой работе не назначались.

## Подключение

В активный D:/AI/Codex/home/config.toml добавлен только mcp_servers.betterdocs с указанным URL. Все прежние байты файла сохранены; штатный codex mcp login завершился успешно. SHA-256 конфигурации после проверки: 46a59e023961604c0ed3db80a85e0bd637168f038dc243c120cec7d60e5ad5ae.

Уже работающий чат не получил новый каталог автоматически. Native App Server прочитал 38 инструментов, но попытка привязать к нему этот активный чат была отклонена из-за active writer. Новые пользовательские чаты и ИИ-исполнители не создавались.

Загрузка проведена официальным Python MCP SDK после отдельного штатного OAuth-одобрения пользователем приложения STRUK draft import. Временный клиент завершён; его токены находились только в памяти. Постоянное подключение Codex сохранено. Серверные настройки, сеть, HTTP/TLS, пароли и доступы других приложений не менялись.

Автоматическая проверка безопасности отклонила попытку чтения Windows Credential Manager как неподходящий способ доступа к учётным данным. Этот код не исполнялся. Дальше использован обычный OAuth-вход, без чтения, экспорта или сохранения секретов в проекте.

## Проверка

Через bd-get-doc повторно прочитаны все 16 сохранённых документов:

- сохранённые блоки точно совпадают с подготовленными итоговыми телами;
- последовательность слов видимого HTML совпадает с исходным Markdown у всех 16 статей;
- YAML и дублирующий H1 удалены из тела;
- все 209 ссылок заменены фактическими адресами созданных документов; цели относятся к этим 16 id;
- единственная ссылка с фрагментом ведёт к существующему якорю; каждому из 92 заголовков задан уникальный в пределах статьи якорь;
- категории, темы, заголовки и draft проверены для каждого документа;
- повторный список содержит ровно 16 документов; итоговый статус BetterDocs — 16 создано, 0 опубликовано;
- в возвращённом HTML есть 4 таблицы.

Проверка относится к сохранённым блокам и HTML API. Внешний вид в браузере/на телефоне, поведение оглавления на странице и поиск по опубликованному разделу не проверены. Авторская приёмка текстов и публикация остаются отдельными действиями.

WordPress записал материалы от имени выдавшего доступ администратора; авторство методологии Юрия обозначено в читательском содержании. Перед публикацией нужно проверить видимую подпись автора.
