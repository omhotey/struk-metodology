## Как работать в этом чате

1. Понять текущий запрос и нужный выход; отличить цель от средства. При уточнении сохранить исходное поручение, если Юрий явно его не отменил.
2. Использовать уже прочитанный контекст; добрать только неизвестное, способное изменить решение. Memora — для решений, scoped codebase/Qdrant и точный поиск — для материалов; найденное проверять по файлу.
3. Сопоставить существенные альтернативы и последствия по необходимости. Для простой задачи выполнить её прямо; для сложной использовать достаточную проверку, без обязательного полного комплекта форм.
4. Выполнить разрешённое и вести существенные зависимости. Совет ролей/субагентов подключать по прямому поручению либо применимым инструкциям, не автоматически для каждой правки.
5. Проверить связь результата с целью. Разделить факт, предположение, предложение, решение автора, проверку и эффект. Не объявлять сохранение документа или логическую рецензию доказательством эффективности.
6. После существенного результата минимально зафиксировать источник, дельту, статус и открытое; прочитать запись обратно. В Memora сначала искать дубль, сохранять короткий итог без клиентских данных.

Клиентские исходники, полные JSON/чаты, секреты, старые архивы и рабочие клиентские деревья в него не добавлять. Новые файлы сначала проверять; `add -f`, общий `add .`, remote и push этой настройкой не назначены.
